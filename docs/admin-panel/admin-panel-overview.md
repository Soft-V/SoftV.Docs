# Admin Panel overview

The main page of the admin panel provides a comprehensive overview of all completed tasks. Here, you can monitor participant results, review task details, and track overall progress. The table displays key data for each submitted task, enabling you to quickly evaluate performance and make informed decisions based on up-to-date information.

- **Task Number** — sequential number of the task within the competition;
- **Task Name** — the name of the task being performed by the participant;
- **Robot Name** — the name or identifier of the robot used by the participant;
- **Score** — the current score achieved for the task;
- **Running Time** — the time taken to complete the task;
- **Send Date** — the date and time when the result was submitted;
- **Username** — the username or login of the participant who submitted the result.

The application allows you to export results to **PDF** format. To do so, click the **Export PDF** button in the application interface, then enter a file name and select a destination folder. The document will be generated based on the current table data and can be used for printing, reporting, or archiving.

<div style={{ textAlign: 'center' }}>
    <img src="/docshome/img/admin-panel/export-en.png"/>
</div>

The application also supports exporting results to **CSV** format. To do so, click the **Export Excel** button in the application interface, then enter a file name and select a destination folder. The **CSV** file contains tabular data and can be opened in any spreadsheet software, such as Microsoft Excel, LibreOffice Calc, or Google Sheets, making it convenient for further processing and analysis.

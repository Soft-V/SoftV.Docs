# Admin Panel

We have developed an **Admin Panel** application specifically designed to simplify the management and oversight of competition workflows. It serves as a centralised dashboard for organisers, providing real‑time visibility into each participant's progress across all tasks.

With the appropriate parent key, you can securely access detailed performance data for every competitor. The panel allows you to monitor task completion status, track time spent on individual assignments, and identify potential bottlenecks in the workflow.

To make data analysis more efficient, the **Admin Panel** offers flexible sorting and filtering options. You can organise results by participant name, score, completion status, or other key metrics. This helps you quickly locate specific entries and gain a clearer understanding of overall performance trends.

For reporting and record‑keeping, the panel supports data export in both **PDF** and **CSV** formats. Whether you need to generate official competition reports, share results with stakeholders, or perform further analysis using external tools, the export functionality ensures that you have the data in the format you need.

# Gamepad

The **Gamepad** page is used to work with a gamepad/joystick. Here you can operate a virtual gamepad when a physical device is not connected to the computer.

When a physical joystick/gamepad is connected to the computer, the virtual gamepad acts only as an indicator and cannot be used to control the robot.

    <img src="/docshome/img/shufflecad/shufflecad_5.png"/>
</div>

You can adjust the dead zone for each analog stick. This parameter defines the minimum stick deflection required to register movement. The value can be set anywhere between 0 (no dead zone — maximum sensitivity) and 15000 (maximum dead zone — only larger stick movements are detected). Increasing the dead zone can help compensate for worn or imprecise sticks, preventing unwanted drift during operation.

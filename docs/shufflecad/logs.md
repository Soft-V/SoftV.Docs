# Event Log

The **Event Log** page is used to view application events and program logs.
<div style={{textAlign: 'left'}}>
<img src="/docshome/img/shufflecad/shufflecad_3.png"/>
</div>

The elements above are provided for convenient management of the log:
- Number of messages;
- Toggle to scroll to the last message when new messages appear;
- Button to write all messages to a single file;
- Button to clear the log.

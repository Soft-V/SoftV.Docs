# Admin Panel

我们开发了 **Admin Panel** 应用程序，专门用于简化和优化竞赛流程的管理与监督。它作为组织者的中央控制面板，提供对每位参与者所有任务进度的实时可视化监控。

通过相应的父级密钥，您可以安全地访问每位参赛者的详细表现数据。该面板允许您监控任务完成状态、跟踪单项任务所花费的时间，并识别工作流程中可能存在的瓶颈。

为了提高数据分析效率，**Admin Panel** 提供了灵活的排序和筛选功能。您可以按参与者姓名、得分、完成状态或其他关键指标对结果进行排序。这有助于快速定位特定条目，并更清晰地了解整体表现趋势。

在报告和记录方面，面板支持以 **PDF** 和 **CSV** 格式导出数据。无论是生成官方竞赛报告、与利益相关者分享结果，还是使用外部工具进行进一步分析，导出功能都能确保您以所需格式获取数据。

# Admin Panel 概述

**Admin Panel**的主页提供了所有已完成任务的全面概览。在这里，您可以监控参赛者的成绩、查看任务详情并跟踪整体进度。表格中展示了每项提交任务的关键数据，使您能够快速评估表现，并根据最新信息做出明智的决策。

- **Task Number** — 任务在比赛中的序号；
- **Task Name** — 参赛者所执行的任务名称；
- **Robot Name** — 参赛者使用的机器人名称或标识符；
- **Score** — 当前任务获得的分数；
- **Running Time** — 完成该任务所用的时间；
- **Send Date** — 提交结果的日期和时间；
- **Username** — 提交结果的参赛者用户名或登录名。

该应用程序支持将结果导出为 **PDF** 格式。使用时，请点击界面中的 **Export PDF** 按钮，然后输入文件名并选择保存位置。生成的文档将基于当前表格数据，可用于打印、报告或归档。

<div style={{ textAlign: 'center' }}>
    <img src="/docshome/img/admin-panel/export-en.png"/>
</div>

该应用程序还支持将结果导出为 **CSV** 格式。使用时，请点击界面中的 **Export Excel** 按钮，然后输入文件名并选择保存位置。**CSV** 文件包含表格数据，可在任何电子表格软件中打开，例如 Microsoft Excel、LibreOffice Calc 或 Google Sheets，方便进行进一步处理和分析。

# 项目启动步骤说明

- 下载 VMX 和 TitanQuad 控制器的固件（相关说明请参阅 robocadV 模拟器中的课程）；
- [下载并将镜像安装到 SD 卡](../robocad/libraries/update/image);
- 从 [SoftHub](../softhub) 下载 [shufflecad](../shufflecad) 应用程序;  
- [为所选编程语言安装必要的组件](download-required);  
- [创建并配置初始项目](create-project);  
- 运行 *shufflecad* 并 [填写启动所需的字段](../shufflecad/start-project).

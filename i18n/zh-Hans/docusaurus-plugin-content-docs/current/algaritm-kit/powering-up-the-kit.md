请勿尝试将电池直接连接到控制器！
:::

:::note
电池为套件中的所有元件提供稳定的电源。但是，可能会出现电涌情况。为防止电路板起火，电机驱动板上 XT60 接口旁边安装了保险丝。若保险丝烧断，可用相同规格（板上有标注）的新保险丝进行更换。

:::

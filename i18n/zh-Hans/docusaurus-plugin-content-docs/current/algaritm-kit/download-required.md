# 安装所需组件

    <TabItem value="python">
    要使用 **robocad** 库，你需要：  
        - 在设备上安装 [Python 3](https://www.python.org/downloads/)；
        - 安装你偏好的 IDE，例如 [PyCharm](https://www.jetbrains.com/pycharm/download)；  
        - 安装 IDE 后，[安装 robocad-py 库](../robocad/libraries/installation/python)。  
    </TabItem>
    <TabItem value="java">
    要使用 **robocad** 库，你需要：
        - 在设备上安装 [Java](https://www.oracle.com/java/technologies/downloads/)；
        - 安装你偏好的 IDE，例如 [IntelliJ](https://www.jetbrains.com/idea/download)；  
        - 安装 IDE 后，[安装 robocad4J 库](../robocad/libraries/installation/java)。  
    </TabItem> 
    <TabItem value="cpp">
        要使用 **robocad** 库，你需要：
        - 在设备上安装 [MSVC v143](https://visualstudio.microsoft.com/ru/downloads/)；
        - 安装你偏好的 IDE，例如 [CLion](https://www.jetbrains.com/ru-ru/clion/download/)；
        - 安装 IDE 后，[安装 robocad-cpp 库](../robocad/libraries/installation/cpp)。 
    </TabItem>
    <TabItem value="cs">
        要使用 **robocad** 库，你需要：
        - 在设备上安装 [.NET 10.0](https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0) 或 [.NET 8.0](https://dotnet.microsoft.com/ru-ru/download/dotnet/8.0)；
        - 安装你偏好的 IDE，例如 [Rider](https://www.jetbrains.com/rider/download/)；
        - 安装 IDE 后，[安装 RobocadCs 库](../robocad/libraries/installation/cs)。
    </TabItem>

# 手柄

**手柄**页面用于使用手柄/摇杆进行操作。当计算机未连接物理设备时，您可以在此操作虚拟手柄。

当计算机连接了物理摇杆/手柄时，虚拟手柄仅作为指示器，无法用于控制机器人。

<div style={{textAlign: 'left'}}>
    <img src="/docshome/img/shufflecad/shufflecad_5.png"/>
</div>

您可以为每个模拟摇杆调整死区。该参数定义了触发移动所需的最小摇杆偏移量。取值范围为 0（无死区——灵敏度最高）到 15000（最大死区——只有较大幅度的摇杆移动才会被识别）。增大死区有助于补偿摇杆的磨损或不精确，防止操作过程中出现不必要的漂移。

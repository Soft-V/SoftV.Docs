# 欢迎使用 shufflecad

**shufflecad** 是面向机器人的桌面环境。
它让您可以运行用户程序、观察其生命周期，并像在构建器中移动积木一样轻松地管理它们。
该应用程序提供了一个可视化控制面板——变量会转化为可在调试时实时更改的指示器和控件。

**shufflecad** 展示了机器人眼中的世界——摄像头画面和图像处理结果——让您看到机器人「看到」和「理解」的内容。所有操作、错误和决策都会汇总到一个便捷的日志记录器中，将晦涩的消息转化为清晰的执行历史。

这不仅仅是一个工具：**shufflecad 是开发者想法与机器人行为之间的接口，让您能够可视化、调优并运行机器的智能。**

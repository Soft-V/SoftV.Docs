# Геймпад

Страница **Геймпад** используется для работы с геймпадом/джойстиком. Здесь вы можете управлять виртуальным геймпадом, если физическое устройство не подключено к компьютеру.

Если к компьютеру подключён физический джойстик/геймпад, виртуальный геймпад работает только как индикатор и не может использоваться для управления роботом.

<div style={{textAlign: 'left'}}>
    <img src="/docshome/img/shufflecad/shufflecad_5.png"/>
</div>

Вы можете настроить мёртвую зону для каждого аналогового стика. Этот параметр определяет минимальное отклонение стика, необходимое для регистрации движения. Значение можно задать в диапазоне от 0 (без мёртвой зоны — максимальная чувствительность) до 15000 (максимальная мёртвая зона — регистрируются только более значительные отклонения стика). Увеличение мёртвой зоны помогает компенсировать износ или неточность стиков, предотвращая нежелательный дрейф во время работы.

# Подключение контроллеров

# Запуск питания набора

В комплект набора входит переходной кабель XT30 (1 на 2), который используется для распределения питания от драйвера на остальную часть системы. 

<img src="/docshome/img/algaritm-kit/other/xt30-parallel.PNG"/>

Подключите одиночный конец кабеля к выходу питания на плате контроллера двигателей.

<img src="/docshome/img/algaritm-kit/driver/driver-power-output.png"/>


Перед подключением переходного кабеля к остальным устройствам к каждому из разветвлённых концов нужно подсоединить стандартный провод с разъёмом XT30. Затем подключите один конец к разъёму питания контроллера.

<img src="/docshome/img/algaritm-kit/shield/shield-power-up.PNG"/>

После этого подключите другой конец кабеля к входу питания блока питания сервоприводов.

<img src="/docshome/img/algaritm-kit/other/servo-power-block-power-up.PNG"/>

Последний шаг — подключить батарею к разъёму XT60 на плате контроллера двигателей. После подключения питание распределяется на все компоненты — сам контроллер двигателей, главный контроллер и блок питания сервоприводов.

<img src="/docshome/img/algaritm-kit/driver/driver-power-up.png"/>



:::danger
Не пытайтесь подключать батарею напрямую к основному контроллеру!
:::

:::note
Батарея обеспечивает стабильное питание для всех элементов набора. Однако возможны скачки напряжения. Чтобы платы не вышли из строя, рядом с разъёмом XT60 на плате контроллера двигателей установлены предохранители. В случае перегорания предохранителя его можно заменить новым такого же номинала, указанного на плате.
<img src="/docshome/img/algaritm-kit/driver/driver-fuses-installation.png"/>
:::

# Связь между контроллерами

Связь между платой контроллера двигателей и главным контроллером устанавливается по USB. Контроллер двигателей оснащён разъёмом **USB Type‑C**, расположенным рядом с разъёмом XT60, а главный контроллер предоставляет порт **USB 3.0**. Используйте USB-кабель, входящий в комплект набора, чтобы соединить обе платы.

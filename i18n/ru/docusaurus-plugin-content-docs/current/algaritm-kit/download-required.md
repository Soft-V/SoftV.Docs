    <TabItem value="python">
    Для работы с библиотеками **robocad** вам понадобится:  
        - установленный на устройстве [Python 3](https://www.python.org/downloads/);
        - удобная для вас IDE, например, [PyCharm](https://www.jetbrains.com/pycharm/download);  
        - после установки IDE [установите библиотеку robocad-py](../robocad/libraries/installation/python).  
    </TabItem>
    <TabItem value="java">
    Для работы с библиотеками **robocad** вам понадобится:
        - установленная на устройстве [Java](https://www.oracle.com/java/technologies/downloads/);
        - удобная для вас IDE, например, [IntelliJ](https://www.jetbrains.com/idea/download);  
        - после установки IDE [установите библиотеку robocad4J](../robocad/libraries/installation/java).  
    </TabItem> 
    <TabItem value="cpp">
        Для работы с библиотеками **robocad** вам понадобится:
        - установленный на устройстве [MSVC v143](https://visualstudio.microsoft.com/ru/downloads/);
        - удобная для вас IDE, например, [CLion](https://www.jetbrains.com/ru-ru/clion/download/);
        - после установки IDE [установите библиотеку robocad-cpp](../robocad/libraries/installation/cpp). 
    </TabItem>
    <TabItem value="cs">
        Для работы с библиотеками **robocad** вам понадобится:
        - установленный на устройстве [.NET 10.0](https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0) или [.NET 8.0](https://dotnet.microsoft.com/ru-ru/download/dotnet/8.0);
        - удобная для вас IDE, например, [Rider](https://www.jetbrains.com/rider/download/);
        - после установки IDE [установите библиотеку RobocadCs](../robocad/libraries/installation/cs).
    </TabItem>

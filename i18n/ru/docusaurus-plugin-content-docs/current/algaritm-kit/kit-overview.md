# Обзор набора Algaritmica

Ядром системы управления является комплект Repka 5 + расширительная плата (shield). Далее подробнее рассмотрим расширительную плату и её возможности.

Плата предоставляет широкий набор интерфейсов ввода-вывода для подключения датчиков, исполнительных механизмов и периферийных модулей. Через неё доступны:

- Аналоговые и цифровые выводы — для работы с широким спектром датчиков и дискретных устройств;
- PWM-выходы — для точного позиционирования сервоприводов;
- Проводные интерфейсы UART, SPI, I2C для высокоскоростного обмена данными с периферийными микросхемами и модулями.

Контроллер двигателей — это четырёхканальная плата драйвера, предназначенная для требовательных робототехнических и автоматизационных задач.

Контроллер двигателей имеет четыре независимых PWM-канала для управления DC-моторами, при этом каждый канал обеспечивает:
- Возможность подачи тока на мотор;
- Два входа концевых выключателей для механического определения крайних положений;
- Вход энкодера для обратной связи по скорости и положению в замкнутом контуре.

Помимо DC-моторов, плата поддерживает два выхода для сервоприводов со стандартным PWM-управлением, а также два выделенных порта для шаговых двигателей.

Для связи между контроллером двигателей и расширительной платой контроллер предлагает интерфейс USB Type-C для быстрой настройки и мониторинга в реальном времени, а также шину CAN 2.0, поддерживающую многоточечные сети с высокой помехоустойчивостью.

# Описание этапов запуска проекта

- Загрузите прошивку для контроллеров VMX и TitanQuad (инструкции приведены в уроках в симуляторе robocadV);
- [Загрузите и установите образ на SD-карту](../robocad/libraries/update/image);
- Загрузите приложение [shufflecad](../shufflecad) из [SoftHub](../softhub);  
- [Установите необходимые компоненты для выбранного языка программирования](download-required);  
- [Создайте начальный проект и настройте его](create-project);  
- Запустите *shufflecad* и [заполните необходимые поля для запуска](../shufflecad/start-project).

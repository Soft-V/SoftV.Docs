# Обзор набора Studica

Основой системы управления является контроллер VMX Robotics Controller. Мы подробнее рассмотрим этот контроллер и его возможности.

VMX — это мощный робототехнический контроллер на базе Linux, который может функционировать как система управления роботом, так и процессор для обработки изображений и движения, поддерживая программирование на Python, Java, C++ и C#. Он предоставляет обширный набор интерфейсов ввода-вывода и построен на многопроцессорной вычислительной платформе Linux с гигабитным Ethernet, портами USB 3.0 и встроенными Wi-Fi/Bluetooth. В основе его сенсорного набора лежит 9-осевой navX-IMU для точного отслеживания ориентации. Через него доступны следующие интерфейсы:

- Аналоговые и цифровые пины — для подключения широкого спектра датчиков и дискретных устройств;
- ШИМ-выходы — для точного позиционирования сервоприводов;
- Интерфейсы CAN, SPI, I2C и UART — для высокоскоростного обмена данными с периферийными микросхемами и модулями в реальном времени.

Titan Quad Motor Controller — это мощная четырёхканальная драйверная плата на базе CAN-шины, предназначенная для решения сложных задач в области робототехники и автоматизации. Она является ключевым компонентом коллекции WorldSkills Mobile Robotics, обеспечивая надёжное и стабильное управление моторами для высокопроизводительных роботов.

Контроллер моторов оснащён четырьмя независимыми каналами для двигателей постоянного тока, каждый из которых предоставляет:
- Возможность подачи тока на мотор;
- Два входа концевых выключателей для механического определения крайних положений;
- Вход энкодера для обратной связи по скорости и положению в замкнутом контуре.

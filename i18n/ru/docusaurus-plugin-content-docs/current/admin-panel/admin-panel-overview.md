# Обзор приложения

На основной странице административной панели отображается сводная информация по всем выполненным заданиям. Здесь вы можете отслеживать текущие результаты участников, просматривать детали выполнения и анализировать прогресс. Таблица содержит ключевые данные по каждому выполненному заданию, что позволяет оперативно оценивать успехи участников и принимать управленческие решения на основе актуальной информации.

- **Номер задачи** — порядковый номер задания в рамках соревнования;
- **Название задачи** — название задания, которое выполняет участник;
- **Название робота** — имя или идентификатор робота, используемого участником;
- **Очки** — текущий набранный балл за выполнение задания;
- **Время выполнения** — время, затраченное на выполнение задания;
- **Дата отправки** — дата и время отправки результата;
- **Имя пользователя** — имя пользователя или логин участника, отправившего результат.

Приложение позволяет экспортировать результаты в формат **PDF**. Для этого нажмите кнопку **Export PDF** в интерфейсе приложения, затем укажите имя файла и выберите папку для сохранения. Документ будет сгенерирован на основе текущих данных таблицы и может быть использован для печати, отчётов или архивирования.

<div style={{ textAlign: 'center' }}>
    <img src="/docshome/img/admin-panel/export.png"/>
</div>

Приложение также поддерживает экспорт результатов в формат **CSV**. Для этого нажмите кнопку **Export Excel** в интерфейсе приложения, укажите имя файла и выберите папку для сохранения. **CSV-файл** содержит табличные данные и может быть открыт в любых программах для работы с электронными таблицами, таких как Microsoft Excel, LibreOffice Calc или Google Sheets, что удобно для дальнейшей обработки и анализа.
